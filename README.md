# E-Storage application 

### Lightweight Cloud Storage for Everyone.

**A lightweight, privacy-focused cloud storage platform built for users with limited device storage, older smartphones, and low-bandwidth internet connections.**

---

## Vision

E-Storage aims to make cloud storage simple, affordable and accessible without requiring expensive devices or high-speed internet.

We believe every smartphone deserves a reliable cloud storage experience, regardless of its age or hardware.

---

## Mission

Build a cloud storage platform that is:
- Fast
- Secure
- Lightweight
- Affordable
- Easy to use
